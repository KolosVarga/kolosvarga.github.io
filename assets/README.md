# Assets

Put these files in this folder and the site picks them up automatically:

| File | Used for |
| --- | --- |
| `portrait.jpg` | Your photo in the About section (portrait 4:5 works best, at least 800×1000). |
| `Kolos_Varga_Resume.pdf` | The "Download resume" button. |

Project images: add them here (e.g. `assets/projects/rover.jpg`) and swap the SVG inside a
project's `<div class="ph">` placeholder for `<img src="assets/projects/rover.jpg" alt="...">`.
